# LLM 推理优化周报（2026-06-08 ~ 2026-06-15，UTC）

## 本周观察摘要

- 本周 vLLM 合并 258 个 PR、SGLang 合并 361 个 PR，活跃度仍极高；两个项目本周的头号主题都是 **DeepSeek-V4（DSv4）的适配与性能打磨**——从 ROCm/XPU/Blackwell 的算子融合、MLA/DSA 解码内核，到 BCG（breakable CUDA graph）、MTP 验证逻辑修复，几乎贯穿所有分类。
- SGLang 这周的"调度/分布式"分类（66 个 PR）异常庞大，核心是对 **Spec V2 / EAGLE 投机解码体系的大规模重构**（`hnyls2002` 主导），逐步废弃 Spec V1、统一 `BaseSpecWorker`/`EagleDraftWorkerBase` 接口，并合入了 DFlash V2、Ngram Spec V2 等新投机解码后端。
- KV cache 方向，SGLang 的 **UnifiedTree/HiCache** 重构上线（HybridModel 默认通过 UnifiedTree 启用分层缓存），vLLM 则新增了 KV cache watermark 抑制 preemption、多级 offloading 异步批量查找等优化。
- 硬件侧 AMD/ROCm、Intel XPU、华为 NPU 的适配 PR 数量都不小，反映出推理引擎正在加速向多元算力生态铺开；Blackwell（SM100）相关的 CuteDSL/FP4 kernel 也持续增加。
- 模型生态方面，本周是"开源大模型爆发周"：**GLM-5.2、MiniMax M3、Kimi K2.7-Code** 接连发布，且都已出现在 vLLM/SGLang 的适配 PR 中（MiniMax-M3 EAGLE3、Kimi K2.7 cookbook 等），NVIDIA Nemotron 3 Ultra 也获得 vLLM Day-0 支持。
